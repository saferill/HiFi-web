Panduan Instalasi & Kebijakan Privasi

Langkah cepat memasang APK di Android dan komitmen transparansi privasi HiFi Music.

📲 Cara Pasang APK di Android

  1. 1Klik tombol Unduh di atas untuk mengunduh file APK yang sesuai dengan arsitektur HP kamu.
  2. 2Buka file APK yang sudah terunduh, lalu aktifkan izin "Install from Unknown Sources" jika diminta sistem Android.
  3. 3Tunggu proses instalasi selesai, buka HiFi, dan langsung nikmati musik tanpa iklan atau login wajib.

🔒 Kebijakan Privasi (Privacy Policy)

  • Tanpa pelacak iklan, analytics pihak ketiga, atau pengumpulan data pribadi.
  • Riwayat putar, daftar putar lokal, dan cache lagu disimpan sepenuhnya di perangkat kamu.
  • Aplikasi hanya terhubung ke layanan pemutaran, lirik (LRCLIB/HiFi-lyrics), SponsorBlock, dan konfigurasi GitHub HiFi.
  • 100% kode sumber terbuka (GPL-3.0) dan dapat diaudit siapa saja di GitHub.

Pertanyaan yang Sering Diajukan

Apakah HiFi gratis dan bebas iklan?

Ya, HiFi 100% gratis, open-source (GPL-3.0), dan tidak memiliki iklan banner, pop-up iklan, maupun pelacak komersial.

File APK mana yang harus saya unduh?

Tombol unduh di atas sudah otomatis memilihkan arsitektur yang cocok (biasanya arm64-v8a untuk HP Android modern). Jika ragu atau gagal pasang, pilih Universal APK.

Apakah HiFi tersedia di F-Droid?

HiFi saat ini sedang dalam tahap pengajuan resmi untuk masuk ke katalog F-Droid agar pembaruan aplikasi ke depannya makin mudah dan terverifikasi.

Bagaimana jika radio live atau tangga lagu bermasalah?

Bot otomatis di GitHub Actions mengecek dan menyembuhkan link radio serta tangga lagu setiap 2 jam sekali. Cukup tutup dan buka ulang aplikasi untuk menyegarkan cache.
